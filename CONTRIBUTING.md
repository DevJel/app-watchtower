# Contributing

Runtime implementation is gated on receipt of the user's coding guidelines.

For each change: link an issue, document the behavior and security impact, add tests, update contracts and migrations, and request review. Never deploy production changes from an unreviewed branch.

Proposed release gates: formatting, lint, type checking, unit tests, Worker integration tests, migration tests, secret scanning, dependency review, and manually approved production deployment. Tooling is not configured in this planning package.
